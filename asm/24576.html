6000: Dictionary letter index
Before the vocabulary proper there is a small index of 16-bit little-endian offsets. Entry n (n=1 for A, 2 for B ... 26 for Z) gives the offset from 6000 of the first dictionary word that begins with that letter. For example the entry for A is $0040, so the A-words start at 6040; the entry for G is $02C1, which is where GANDALF lives. The parser uses this to jump straight to the right part of the dictionary instead of scanning the whole thing.
Entry 0 is unused ($0000). After Z come a few more words, including $07AC, which points into the second (message-only) dictionary at 67B0.
