6F3E: Start a dictionary search for the typed word
Copies the letters of the word at HL into the buffer at 7071, keeping only the low five bits of each (so 'a' and 'A' are both 1). Characters below $40 (space, punctuation, ENTER) end the word. The number of letters is stored at 7081.
The first letter (1-26) is then used to index the letter table at 6000, and IX is set to the first dictionary word starting with that letter. Execution continues into 6F69 to unpack it.
Input
HL Start of the typed word
Output
HL End of the typed word
IX Dictionary word
F Z set if the dictionary word starts with the right letter

6F43 LD A,(HL) A = (HL)

6F55 LD HL,($7071) Look up the first letter in the letter index

This entry point is used by 6E8E to move on to the next dictionary word. It saves IX in $B607 as the current candidate and then unpacks it. Another entry point at 6F6D does the same without updating $B607; the tokeniser uses that one to peek at the following word.
6F69 LD ($B607),IX Store IX in the current dictionary word
Check that the dictionary word at IX starts with the same letter as the typed word. If not, return with Z reset: the search is over.
6F6D LD A,(IX+$00) A = (IX+0)

6F72 LD B,A B = A
6F73 LD A,($7071) A = the contents of 7071
6F76 CP B Compare with B
6F77 RET NZ Return if no
Unpack the dictionary word into 7082. The same end-of-word rule is used everywhere: bit 7 marks the last letter, except in the first two bytes. Letter codes of 0 (padding) are not copied.
