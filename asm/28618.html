6FCA: Clear the screen
Sets the border to white, clears the whole display file ($4000-$57FF) to 0 and sets all 768 attributes ($5800-$5AFF) to $38: black ink on white paper, the colours The Hobbit uses throughout. Called once at start-up (6C27) before the frame and first text are drawn.
6FCA PUSH HL Save HL
6FCB PUSH DE Save DE
6FCC PUSH BC Save BC
6FCD LD A,$07 White border
6FCF OUT ($FE),A Write to the port (border colour, beeper or printer)
6FD1 LD HL,$4000 Clear the pixels
6FD4 LD DE,$4001 DE = $4001
6FD7 LD BC,$1800 BC = $1800
6FDA LD (HL),$00 Store $00 at (HL)
6FDC LDIR Copy BC bytes from HL to DE
6FDE LD BC,$0300 Black on white attributes
6FE1 LD (HL),$38 Store $38 at (HL)
6FE3 LDIR Copy BC bytes from HL to DE
6FE5 POP BC Restore BC
6FE6 POP DE Restore DE
6FE7 POP HL Restore HL
6FE8 RET Done
