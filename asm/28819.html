7093: Token buffer
The tokens for the current input line, two bytes each, high byte first, as built by the main loop (6D0A) from the results of 6E8E and read by the parser (7C4F). Space for 32 tokens. Because it is only rebuilt when a new line is typed, the '@' key (6E71) can repeat the previous command by parsing it again.
