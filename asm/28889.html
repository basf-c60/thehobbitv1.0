70D9: Clear a block of memory
Writes B zero bytes starting at HL. A tiny utility used to clear the token buffer and other work areas.
Input
B Number of bytes to clear
HL Start address
70D9 XOR A A = 0
70DA LD (HL),A Clear this byte
70DB INC HL Move on to the next one
70DC DJNZ $70DA Repeat for however many bytes were asked for
70DE RET
