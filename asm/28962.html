7122: Report the action ("you attack thorin with the sword.")
Prints the sentence that describes what an actor has just done, for example 'you go east.', 'thorin attacks you.', 'gandalf opens the round green door.' or 'you attack thorin with the short strong sword.'. It is built from the entry for the current action (number in $B5D8) in the action table AA47, whose four word slots hold the verb, a particle, a preposition and (for movement) GO.
The flags collected by 70EA decide what is printed. If bit 4 of them is set the action is silent and nothing is printed at all.
Otherwise the actor's name is printed (739E: 'you', 'thorin', 'gandalf'...). If the action was only being tried and would have failed ($B5EC is 0) the word CANNOT is inserted, so the report reads 'you cannot open the door'. The verb follows (74B1). For the ten movement actions a special case applies when the actor is a character and the move is not possible: the word SOMEWHERE is printed instead of the direction. Then, as the flags require, the particle, the target object (73AB, with its article) and the preposition plus instrument (73BE) are added. The sentence ends with a full stop and a new line.
The printing is done with $70D6 set to 1, which makes 7436 use 'the' rather than 'a' for articles. $B5F2 is set when the action is only being tried, which sends the text to the lower window instead (see 7580).
