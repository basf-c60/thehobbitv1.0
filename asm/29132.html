71CC: Get the address of a room's word list
Returns HL pointing at the name words of room A (the record address from 9B0C plus 2). IX is preserved. Used when a message needs to name a room rather than an object.
Input
A Room number
Output
HL Room name words
71CC PUSH IX Save the caller's IX
71CE CALL $9B0C IX = room A's own record
71D1 PUSH IX HL = that same address...
71D3 POP HL
71D4 INC HL ...moved on 2 bytes, to the room's own name words
71D5 INC HL
71D6 POP IX Restore the caller's IX
71D8 RET
