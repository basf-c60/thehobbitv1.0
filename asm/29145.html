71D9: Get the address of an object's word list
Returns HL pointing at the four word slots of object A (its record address from 9B25 plus 8: the noun and adjectives). DE and IX are preserved.
Input
A Object number
Output
HL Object's words
71D9 PUSH DE Save the caller's DE
71DA PUSH IX Save the caller's IX
71DC CALL $9B25 IX = object A's own record
71DF PUSH IX HL = that same address...
71E1 POP HL
71E2 LD DE,$0008 ...moved on 8 bytes, to the object's own word slots
71E5 ADD HL,DE
71E6 POP IX Restore the caller's IX
71E8 POP DE Restore the caller's DE
71E9 RET
