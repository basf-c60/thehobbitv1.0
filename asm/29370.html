72BA: Print a character from a message
Used by the message interpreter for literal characters and control code $0D. The character is printed (7580) and, if it was a carriage return, the 'last punctuation' flag at $B5F5 is cleared.
72BA CALL $7580 Print the character
72BD CP $0D Was it a new line?
72BF RET NZ No: nothing more to do
72C0 XOR A Yes: a fresh line has begun, so clear the "last punctuation" flag
72C1 LD ($B5F5),A
72C4 RET
