72CA: Print a message, suppressing actions inside a quotation
If the parser is inside a quotation ($B60B set), the 'really do it' flag $B5EB is cleared first, so that commands being passed to another character are only tried, not carried out. Execution continues into 72D4.
72CA LD A,($B60B) Are we in the middle of a quotation (an order being given to a character)?
72CD AND A
72CE JR Z,$72D4 No: print the message as normal
72D0 XOR A Yes: make sure this only counts as a trial, not something that really happens to the world...
72D1 LD ($B5EB),A ...then fall into the ordinary message printer
