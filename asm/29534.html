735E: Message code $00: print an object passed on the stack
The caller of 72D4 pushed the address of an object's word list before calling. This handler reaches past the interpreter's own return addresses (POP DE / POP HL / EX (SP),HL / PUSH DE), removes that parameter, and prints the object's name (742B) unless the address is 0. The 'use an article' flag B5F4 is cleared first, so no article is printed. Returns with Z set.

7368 CALL NZ,$742B If not, print the object's name
