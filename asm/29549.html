736D: Message code $01: print a word passed on the stack
Removes a word reference that the caller pushed on the stack (in the same way as 735E) and returns it in DE with Z reset, which makes the interpreter print it.
736D POP DE Reach past the interpreter's own two return addresses...
736E POP HL
736F EX (SP),HL ...to find the word the caller pushed, lifting it out...
7370 PUSH DE ...and putting the two return addresses back
7371 EX DE,HL DE = that word
7372 OR $01 Make sure A is not zero...
7374 RET ...so the interpreter is told to print the word now in DE
