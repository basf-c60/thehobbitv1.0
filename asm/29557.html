7375: Message code $02: relative jump
Moves the message pointer IX by the signed byte that follows the code, so a message can skip over part of itself or loop. Returns with Z set. The entry point at $7382 (XOR A / RET) is used by the codes that do nothing.
7375 LD E,(IX+$01) E = the signed jump distance that follows this code
7378 LD D,$00
737A BIT 7,E Is it negative?
737C JR Z,$7380
737E LD D,$FF If so, sign-extend it into D
7380 ADD IX,DE Move the message pointer by that many bytes
7382 XOR A Tell the interpreter to just carry on from the new position
7383 RET
