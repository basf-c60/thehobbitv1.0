73A6: Message code $07: print the target
Prints the target of the command (object $B5D9) with its article. If $B5EF is set, the target is a room rather than an object, and the room's name is used instead (71CC rather than 71D9). The entry at 73AB is used by 7122. Code $08 (73B4) prints a backspace, and code $09 (73B9) sets the article flag and continues into 73BE.
