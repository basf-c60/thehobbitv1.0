73B4: Message codes $08 and $09
Code $08 ($73B4) prints a backspace, so that a word can be joined to the one before it (for example to add a suffix). Code $09 ($73B9) sets the 'print an article' flag and prints the instrument with its article, continuing into 73BE.
73B4 CALL $7580 CODE $08: print a backspace, joining this word onto the one before it
73B7 XOR A Nothing further to print
73B8 RET
73B9 LD A,$01 CODE $09: an article is wanted...
73BB LD ($B5F4),A ...then fall into the shared code below, which prints the instrument
