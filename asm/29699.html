7403: Message code $10: "you are" or "thorin is"
Prints the actor's name (747F) and then returns ARE if the actor is Bilbo and IS otherwise, for the interpreter to print. Code $11 (741C) does the same for the target, and code $13 (7424) for an object pushed on the stack.
