747F: Print the name of object A
Prints the name of object A. Object $FF (nobody) is printed as SOMEONE, which is what you see when an unseen character does something: 'someone opens the door'. Otherwise it continues at $73CD in 73BE.
Input
A Object number
747F CP $FF Is there no object at all ($FF, for an attacker Bilbo cannot see)?
7481 JP NZ,$73CD If there is a real object, print its name as usual
7484 LD DE,$0AE3 No object: SOMEONE
7487 JP $74B8 Print that instead
