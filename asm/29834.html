748A: Print an abbreviated word
Message bytes $60-$7F stand for the 32 most common words. The byte minus $60 indexes the table at AC31 to get a dictionary reference (the high byte has $50 added so it lands in the right flag range), and then the word is printed exactly as if it had been written out in full, by jumping back into 72D4.
748A SUB $60 A = which of the 32 common words this is (the code minus $60)
748C LD E,A
748D LD D,$00
748F LD HL,$AC31 HL = the table of abbreviated words
7492 ADD HL,DE HL = this word's own entry (2 bytes each)...
7493 ADD HL,DE
7494 LD E,(HL) DE = the word reference, low byte...
7495 INC HL
7496 LD A,(HL) ...then the high byte, with $50 added, to bring it into range...
7497 ADD A,$50
7499 LD D,A
749A JP $7308 Print it exactly as an ordinary word reference
