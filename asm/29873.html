74B1: Print a word from a list
Fetches the word reference at HL (low byte first), moves HL on by two, strips the flag bits and falls into 74B8 to print it. Used to print the words of action table entries and object names one at a time.
Input
HL Word reference
Output
HL Next word
74B1 LD E,(HL) DE = the next word reference in the list, low byte...
74B2 INC HL
74B3 LD A,(HL) ...then the high byte...
74B4 INC HL
74B5 AND $0F ...with its flag bits stripped away
74B7 LD D,A
