7580: Print a character
The main character output routine. It does nothing if 756B says printing is switched off.
If $B5F2 is set, the character goes to the lower (input) window via 75AD, which is how the player's own typing, and replies such as 'I don't know the word', appear down there. Otherwise it goes to the upper story window via 7694.
Then comes one of the game's jokes. If the flag at $B5F1 is set, every S (or s) printed in the story window is followed by an H. That flag is set when Bilbo drinks the wine (the wine's object record calls A9ED), and cleared five turns later by timer 7 (A9FF). So for a while after drinking, the game slurs: 'you drink shome wine. gandalf goesh easht.'
