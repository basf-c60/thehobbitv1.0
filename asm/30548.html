7754: Move back one character position
Moves the story window's print position back 6 pixels: C (the bit offset within the screen byte) is reduced by 6, and if that goes below zero it has 8 added and L is moved back one byte.
Input
C Bit offset
L Screen address (low byte)
7754 LD A,C A = the pixel offset within the current screen byte
7755 SUB $06 Move back 6 pixels, the width of one character
7757 LD C,A
7758 RET NC Still within the same byte: done
7759 ADD A,$08 Crossed into the byte before: wrap the offset round...
775B LD C,A
775C DEC L ...and step back to that earlier byte
775D RET
