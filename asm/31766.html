7C16: Keyboard table (SYMBOL SHIFT)
The character for each key when SYMBOL SHIFT is held. Most keys give the same as 7BEE; the differences are SYMBOL SHIFT with 2 ('@', repeat the last command, 6E71), 0 ($18, delete the whole line, 6E82), P (double quote, for speech), M (full stop), N (comma) and SPACE ($02).
