7CBB: Is the parser inside a quotation?
Returns with Z reset if $B60B is non-zero (inside a quotation), Z set otherwise.
7CBB LD A,($B60B) A = how many levels of quotation we are inside
7CBE AND A Is that zero (not inside any quotation at all)?
7CBF RET Z set means not in a quotation; NZ means we are
