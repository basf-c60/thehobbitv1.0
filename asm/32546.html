7F22: Parser: move on to the next frame
Finds the next frame (7F6F) and makes it the current one (IY).
7F22 CALL $7F6F IX = the next frame (24 bytes lower, since frames are built downwards)
7F25 PUSH IX IY = that same frame...
7F27 POP IY ...which becomes the current one
