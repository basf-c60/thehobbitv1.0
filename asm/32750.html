7FEE: Parser: syntax error
Called when a word turns up where it is not allowed. Inside a quotation the word is simply skipped. Otherwise the parser's own return address is discarded and 7FF9 prints 'what?'.
7FEE CALL $7CBB Are we inside a quotation (an order to a character)?
7FF1 RET NZ Yes: quietly ignore the bad word and let the order carry on
7FF2 POP HL No: throw away our own return address, since the rest of this line is being abandoned
This entry point is used by the routines at 7DB6, 7DFB and 8072.
7FF3 CALL $7CBB Check again (the same test, just to be sure)
7FF6 JP NZ,$7C7E If it now looks like we ARE in a quotation after all, go back into the parser as if nothing had gone wrong; otherwise fall straight into 7FF9 below and print "what?"
