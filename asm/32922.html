809A: IT
Replaces IT with the object most recently mentioned: the noun and two adjectives saved at $B5D1 (by 8614 each time a command names a target) are copied into the noun phrase buffer, which is then stored in the frame (80AF). So 'take the key. unlock the door with it.' works.
809A PUSH DE Save DE
809B LD HL,$B5D1 HL = the words remembered for IT (the last object named)
809E LD DE,$7C49 Copy them into the noun-phrase buffer currently being built
80A1 LD BC,$0006
80A4 LDIR
80A6 POP DE Restore DE
80A7 BIT 7,E Is the first noun phrase still empty?
80A9 CALL $80AF Store this phrase in whichever slot is free
80AC JP $7C7E Go back to reading the next word
