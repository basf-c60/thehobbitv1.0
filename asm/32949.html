80B5: Opening quotation mark
Begins a quotation, as in SAY TO THORIN "GO EAST". The current word class and frame count are saved ($8007, $8008), and the parser is re-entered at $7C54 with the frame pointer moved to a fresh frame, so that the words inside the quotation are parsed as complete commands of their own.
80B5 LD A,D Save the word class we had reached...
80B6 LD ($8007),A
80B9 PUSH DE ...and DE, BC and IY, so the parser can be restored exactly when the quotation closes
80BA PUSH BC
80BB PUSH IY
80BD LD A,($B5F7) Save the frame count too
80C0 LD ($8008),A
80C3 LD DE,$FFE8 Move on to a fresh frame (24 bytes higher, since frames are built downwards)
80C6 ADD IY,DE
80C8 LD A,$01 One level deeper inside a quotation
80CA JP $7C54 Start parsing again, from a clean state, for the words inside the quotes
