8209: LOAD
Loads a saved game from tape using the ROM routine LD-BYTES ($0556), in four headerless blocks: the 28 game variables (B5CB, from $B5DC), the object table (C00B), the timers and characters (C973) and the room table (B97A). These are exactly the areas that the game backs up at start-up (6C00), and together they are the entire state of the game. Afterwards three bytes are copied from $B5DC back to $C8D1 (see 8284). If a block fails to load, 8250 reports a tape error and restarts the game.
Two things live outside the four blocks. The three bytes of Bard's current order are handled specially (see 8284). But the address of the hidden route chosen at the start of the game is not saved at all: 970B writes it into the code of Elrond's map routine (the operand at $A6C5), not into the saved data.
