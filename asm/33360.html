8250: Load a block, or restart on a tape error
Calls LD-BYTES. If it fails, prints 'tape error - hit any key to restart program', waits for a key and restarts the game (6C27), because a half-loaded game state could not be trusted.
8250 CALL $0556 The ROM's own LD-BYTES routine
8253 RET C Loaded successfully: carry on
8254 LD A,$01 Failed: print in the lower window
8256 LD ($B5F2),A
8259 LD HL,$B249 "tape error - hit any key to restart program."
825C CALL $72D4
825F XOR A Wait for a key
8260 IN A,($FE)
8262 AND $1F
8264 CP $1F
8266 JR Z,$825F
8268 JP $6C27 Restart the game (a half-loaded state cannot be trusted)
