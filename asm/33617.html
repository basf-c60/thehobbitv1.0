8351: Execute a command and run the turn
Called by the main loop (6D0A) after parsing. It works through the command frames built by the parser, one per command, starting at B8B8.
For each frame, 83A7 finds the action and the objects it applies to. If that fails, the frame is dropped. Otherwise the action is carried out for real: $B5EB is set to 1, 7122 reports it ('you take the sword.'), 946F performs it, and 9611 ends the turn, letting the characters act and the timers run. So every command the player types costs one turn, and a line with three commands costs three turns.
A command with ALL is repeated ($837F) for each object it applies to, one turn each. When a frame is finished, the next frame (24 bytes lower) is taken, skipping the exception frames of ALL EXCEPT, until the frame count $B5F7 reaches 0.
If the previous command was left unfinished ($B60A), it is picked up again at $8385 instead.
