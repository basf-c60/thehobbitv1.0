83A7: Find the action and objects for a command
The target ($B5D9) and instrument ($B5DA) are set to $FF (none) and the work area is cleared. 858F then finds the action table entry that matches the frame's verb, particle and preposition; if none does, the routine returns with Z set.
The action number (1-59) is worked out from the entry's address and stored in $B5D8. The flags of the entry (8569) say whether the action needs a target and an instrument (bits 3 and 2 of $B60D). If it needs neither, the routine is done. Otherwise 8405 searches for suitable objects, trying each candidate with a dry run. If the objects cannot be decided, 87AD deals with it (asking 'which key?', saying 'I do not see the key', and so on). With ALL, 8464 moves on to the next object.
