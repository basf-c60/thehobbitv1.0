8405: Search for a target and an instrument
Tries the objects that fit the noun phrases of the command, in two nested loops: for each candidate target (86BC) it tries each candidate instrument (8708). For every combination, a dry run of the action (84DE, which runs the action with $B5EB clear) says whether it would work. The first combination that works is kept. Counts of the candidates are kept at $8330-$8332 so that 87AD can tell whether there were none, one or several.
When only one candidate is allowed ($8344), the search stops after the first.
