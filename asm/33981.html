84BD: Choose the object table to search
Sets IX to the object index at BF53 if the low two bits of A are 0, or to $BF50 (three bytes earlier, which makes the search start with a dummy entry) otherwise.
84BD LD IX,$BF53 IX = the ordinary object index...
84C1 AND $03 Do the flags call for characters only, or objects only?
84C3 RET Z Neither: the ordinary index is fine as it is
84C4 LD IX,$BF50 Otherwise start one entry earlier, so the very first search step lands on the true first entry
84C8 RET
