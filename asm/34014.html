84DE: Try the action (dry run)
Runs the action with 946F and returns with Z set if it would not work ($B5EC is 0). Called while $B5EB is 0, so nothing actually happens and nothing is printed.
84DE CALL $946F Carry out the action, with nothing yet really happening
84E1 LD A,($B5EC) Did it say it would work?
84E4 AND A
84E5 RET
