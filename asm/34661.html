8765: Leave the command unfinished
Saves the current frame at B8B8 and stores A in $B60A, so that the next thing the player types is used to complete this command. Used after 'which key?' and '... what?'.
8765 LD ($B60A),A Remember which situation this is (which key?/what with?/...), for 8351 to recognise next time
8768 PUSH IY HL = the current frame
876A POP HL
876B LD DE,$B8B8 Save the whole 24-byte frame at B8B8 permanently...
876E LD BC,$0018
8771 LDIR ...so the next thing the player types can be merged into it (7CC0)
8773 RET
