8907: Obey an order
Called with A non-zero by 976C when a character has been given an order by the player. The order's slot is found (88EC) and freed, and the 24-byte frame stored in it is matched to an action and objects exactly as if the player had typed it (83A7), but with the quotation flag set so that nothing is printed while this happens. If the action would work (84DE), the character will carry it out on its turn; if not, all the character's orders are cancelled (894D).
With A=0 it only frees the slot.
