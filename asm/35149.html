894D: Cancel a character's orders
Clears every slot of the orders buffer (B628) that is addressed to character A. Used when a character cannot carry out an order and when a character dies (96DD).
Input
A Character
894D PUSH HL Save HL, DE and BC
894E PUSH DE
894F PUSH BC
8950 LD HL,$B628 HL = the start of the orders buffer
8953 LD DE,$0019 DE = 25, the size of one slot
8956 LD B,$08 Eight slots to check
8958 CP (HL) Is this slot addressed to character A?
8959 JR NZ,$895D No: leave it alone
895B LD (HL),$00 Yes: free the slot
895D ADD HL,DE Move on to the next slot
895E DJNZ $8958
8960 POP BC Restore BC, DE and HL
8961 POP DE
8962 POP HL
8963 RET
