8ACC: Test a pixel
Returns with Z reset if the pixel at (D,E) is set.
Input
D x
E y
8ACC PUSH HL
8ACD CALL $8BBC HL = the screen byte, A = the bit for the pixel
8AD0 AND (HL) Z reset if the pixel is set
8AD1 POP HL
8AD2 RET
