8AF5: Move an attribute address left
Decreases HL, unless that would move it out of the attribute file.
8AF5 PUSH AF Save AF
8AF6 DEC HL Move HL one cell left
8AF7 LD A,H Did that go off the left edge of the attribute file?
8AF8 CP $57
8AFA JR NZ,$8AFD
8AFC INC HL If so, undo the move: stay put
8AFD POP AF Restore AF
8AFE RET
