8C3A: Is the actor carrying the target?
Returns normally if the actor is carrying the target (9BCD). If not, it prints 'you are not carrying it.' and returns to the caller's caller, so the action goes no further.
8C3A CALL $9BCD Is the target held by the current actor?
8C3D RET C Yes: carry on with whatever the caller wanted to do next
8C3E POP HL No: throw away the caller's own return address...
8C3F LD HL,$ACE4 ..."you are not carrying it."
8C42 JP $72D4 ...and print that instead, ending the action here
