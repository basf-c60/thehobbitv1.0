8FCF: DIG (the sand)
The sand's DIG handler: digging opens it (9081), revealing anything buried in it; digging again closes it.
8FCF CALL $9C99 Dry run? Then stop here: it would work
8FD2 LD IX,($B5F8) IX = the sand's own record
8FD6 BIT 5,(IX+$07) Is it already open (dug)?
8FDA JP Z,$9081 No: open it, as if by OPEN (revealing whatever is buried)
8FDD JP $90AF Yes: close it again instead (covering things back up)
