9436: Could the action apply to this target?
Used while choosing between candidate objects (86ED). Sets $B5EC to 1 if the action could possibly apply to the target: either there is a default handler for the action (C61F), or the target itself has a handler for it (9ADC). The checks in A100 are also applied. Sets $B5EC to 0 if the action is not possible at all, for example when the target is the actor.
