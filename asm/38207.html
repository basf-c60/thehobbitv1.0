953F: Let a character react to what was done to it
If the object at IX is a living character (bit 6 of its flags set, bit 3 clear), 99FB is called with the action number in B, which may switch the character to a new behaviour (for example, to fight back when attacked).
Input
IX Object record
B Action number
953F BIT 6,(IX+$07) Is the object at IX a living character?
9543 RET Z No: nothing reacts
9544 BIT 3,(IX+$07) Is it already dead?
9548 RET NZ Yes: the dead do not react either
9549 CALL $99FB Give it a chance to switch its behaviour in response to what was just done to it
954C RET
