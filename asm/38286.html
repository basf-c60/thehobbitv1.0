958E: Describe a room
Prints the full description of room A. The message used for this is 'you are <preposition> ...' at AEEE, and before printing it this routine writes the room's preposition - OUTSIDE, INSIDE, IN, ON or AT, chosen by bits 1-3 of the room's first byte from B970 - into the message itself, at AEEF. So the text of the message is changed each time a room is described. 95B9 then does the rest.
Input
A Room number
