95E4: Print a room's name or description
If Z is reset, HL is a description script and it is printed. Otherwise the three name words of the room (from offset 2 of the record at IX) are printed with 9E1F.
95E4 JP NZ,$72D4 Does the room have its own description script (rather than needing its name printed)?
This entry point is used by the routine at 9606.
95E7 LD DE,$0002 A room's own name words start 2 bytes into its record
95EA PUSH IY Save the caller's IY
95EC PUSH IX Copy the room's record into IY as well...
95EE POP IY
95F0 ADD IY,DE ...then move it on to the name words
95F2 CALL $9E1F Print the room's own name (as a noun with adjectives)
95F5 POP IY Restore the caller's IY
95F7 RET
