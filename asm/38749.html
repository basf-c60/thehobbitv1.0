975D: Is the action really happening?
Returns to the caller only if both $B5EB (really do it) and B5EC (it would work) are set. Otherwise it discards the caller's return address, so the caller returns at once.
975D PUSH BC Save BC
975E LD BC,($B5EB) B = "it would work", C = "really happening"
9762 LD A,C
9763 AND B Are both true?
9764 JR NZ,$9767 Yes: carry on normally
9766 POP BC No: discard the caller's own return address too...
9767 POP BC ...so control passes back one level further, skipping whatever the caller was about to do
9768 RET
