9A5D: Prepare for the characters' turn
Notes the room Bilbo is in ($B5E6, 9ECB) and whether it is dark there ($976A). It is also the default handler for action 0 in C61F, which makes it a harmless 'do nothing special' routine.
9A5D LD A,$00 A = 0 (Bilbo)
9A5F CALL $9ECB A = Bilbo's own room
9A62 LD ($B5E6),A Remember it, for 9A28 and the character loop to compare against
9A65 CALL $954D Is it too dark for Bilbo to see?
9A68 LD A,$00 Assume not
9A6A JR NC,$9A6D
9A6C INC A It is dark
9A6D LD ($976A),A Remember whether Bilbo is in the dark, for the rest of this turn
9A70 RET
