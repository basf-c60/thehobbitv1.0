9C42: Total weight of an object's contents
Returns in A the total weight (byte 3) of everything held by object A, including the contents of containers, found by 9C55. The result is $FF if it overflows.
Input
A Object
Output
A Weight
9C42 PUSH BC TOTAL WEIGHT: save the caller's BC
9C43 LD B,$00 B=0 tells the shared routine below to add up weights
This entry point is used by the routine at 9C3D.
