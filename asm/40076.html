9C8C: Get the actor's room record
Returns IX pointing at the record of the room the actor is in. AF is preserved.
9C8C PUSH AF Save AF, so this can be used freely without upsetting the caller's flags
9C8D LD IX,($B5FC) IX = the current actor's own record
9C91 LD A,(IX+$10) A = the actor's location (the first location byte of their record)
9C94 CALL $9B0C IX = that room's own record
9C97 POP AF Restore AF
9C98 RET
