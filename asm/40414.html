9DDE: Get the actor's room's exits
Returns IX pointing seven bytes into the actor's room record, so that 9AEE, which adds 3, arrives at the first exit.
9DDE PUSH DE Save the caller's DE
9DDF CALL $9C8C IX = the current actor's room's own record
9DE2 LD DE,$0007 A room's list of exits starts 7 bytes into its record
9DE5 ADD IX,DE
9DE7 POP DE Restore the caller's DE
9DE8 RET
