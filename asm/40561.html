9E71: Find the exit through a given door
Searches the actor's room for an exit whose door (byte 1) is object A. This routine and 9E76 are one routine: they write 1 or 2 into the offset of the LD A,(IX+n) instruction at $9E89 to choose which byte of each exit is compared.
9E71 PUSH AF FIND EXIT THROUGH A DOOR: save AF
9E72 LD A,$01 1 picks out an exit's DOOR byte for the shared code below
