9EBF: Report failure
During a dry run, sets B5EC to 0 (the action would not work). When the action is really being done, reports it instead (7122), so the player sees 'you cannot ...'.
9EBF LD A,($B5EB) Is this action really happening (not just being tried out)?
9EC2 DEC A
9EC3 JP Z,$7122 Yes: report it as an outright failure ("you cannot ...")
9EC6 SUB A Only a trial: just note that it would not have worked, without printing anything
9EC7 LD ($B5EC),A
9ECA RET
