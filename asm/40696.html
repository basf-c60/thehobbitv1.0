9EF8: List the objects held by A in room B
Lists the objects (9F10) and prints ' nothing' if there were none.
9EF8 PUSH IY Save the caller's IY, DE and BC
9EFA PUSH DE
9EFB PUSH BC
9EFC LD C,$00 C will count how many things get printed
9EFE LD D,$04 D = 4, meaning "no indent yet", since this is a fresh list rather than something nested inside another
9F00 CALL $9F10 List the objects, updating the count in C as it goes
9F03 SUB A Was anything at all printed?
9F04 CP C
9F05 LD HL,$B22D " nothing"
9F08 CALL Z,$72D4 If nothing was printed, say so
9F0B POP BC Restore the caller's BC, DE and IY
9F0C POP DE
9F0D POP IY
9F0F RET
