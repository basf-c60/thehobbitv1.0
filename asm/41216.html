A100: Should the instrument's handlers be used?
Returns with Z set if the current action is one of the five listed at $A13B: DROP IN, PUT IN, PUT ON, TAKE OUT OF and THROW THROUGH. For these it is the instrument (the container, or the window) that knows what to do, so 946F uses its handlers.
A100 PUSH HL Save the caller's HL and BC
A101 PUSH BC
A102 LD B,$05 Five actions to check against
A104 LD HL,$A13B HL = the list of actions that use the instrument's own handlers, rather than the target's
A107 LD A,($B5D8) A = the action being carried out right now
A10A CP (HL) Is it one of these five?
A10B JR Z,$A110 Yes: stop here, with it found
A10D INC HL No: look at the next one in the list
A10E DJNZ $A10A
A110 POP BC Restore the caller's BC and HL
A111 POP HL
A112 RET
