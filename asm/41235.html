A113: A character speaks
Prints '<actor> says "<message at HL>".'. Used by the character routines for Thorin's 'hurry up', Gollum's riddles and so on.
Input
HL Message
A113 PUSH HL Save the caller's HL
A114 LD HL,$AEFB '<actor> says "'
A117 CALL $72D4
A11A POP HL Restore HL: the message to be spoken
A11B LD A,$01 Force a capital letter, as if this were starting a fresh sentence
A11D LD ($B5F5),A
A120 CALL $72D4 Print what is being said
A123 LD HL,$AF01 '"' (the closing quote and a full stop)
A126 JP $72D4
