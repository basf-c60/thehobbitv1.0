A129: Is the target locked or open?
Tests the target's flags: returns Z reset and A=$80 if it is locked; otherwise tests bit 5 and returns A=$85, so Z reset means it is open. The codes in A are for A09C. The entry at $A134 does only the second test.
A129 LD IX,($B5F8) IX = the target's own record
A12D BIT 0,(IX+$07) Is it locked?
A131 LD A,$80 A = the state code for LOCKED/UNLOCKED, in case the caller needs to report it
A133 RET NZ Locked: return with Z reset, telling the caller it cannot be used yet
This entry point is used by the routine at 93ED.
A134 BIT 5,(IX+$07) Not locked: is it open?
A138 LD A,$85 A = the state code for OPEN/CLOSED, in case the caller needs to report it
A13A RET Z reflects whether it is open
