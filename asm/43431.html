A9A7: Timer 5 tick: the magic door opens and an elf sweeps past
Timer 5 is started when an invisible Bilbo examines the magic door (A614: 'the magic door warns of elves approaching'). When its count reaches 1, the magic door (object 13) opens, and if Bilbo is in room 28 or 30 he sees 'the magic door opens.' and 'an elf sweeps past.' Then the ring check of timer 6 is run (A9D4), which takes the ring off anyone wearing it.
A9A7 LD HL,$C277 HL = the magic door's flags
A9AA SET 5,(HL) Open it
A9AC LD HL,$AF29 "the magic door opens."
A9AF CALL $A9BB Print it if Bilbo is nearby
A9B2 LD HL,$B005 "an elf sweeps past."
A9B5 CALL $A9BB
A9B8 JP $A9D4 Take the ring off whoever is wearing it
