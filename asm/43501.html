A9ED: Handler for the wine: Bilbo gets drunk
Attached to the wine's DRINK handler. If the drinker is Bilbo, the flag at $B5F1 is set and timer 7 started, so that for five turns every S he sees is followed by an H (7580).
A9ED LD A,($B5DB) Is the drinker Bilbo?
A9F0 CP $00
A9F2 RET NZ No (a character): nothing happens
A9F3 LD A,$01 Yes: set the "drunk" flag...
A9F5 LD ($B5F1),A
A9F8 LD A,($C9A4) ...and start timer 7 (copy its reload value into its count)
A9FB LD ($C9A5),A
A9FE RET
