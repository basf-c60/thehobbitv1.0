B5CB: Game variables
Working variables. Those identified so far:
  • $B5CB - address of the current word in the input line (for error messages)
  • $B5DA - object number of the weapon/instrument in the current command, or $FF
  • $B5DB - the current actor: 0 when the player is acting, otherwise the object number of the character
  • $B5E1 - set when a timer has expired this turn (9611)
  • $B5E4 - the room in which the eyes timer was started (C6CC)
  • $B5EB - 1 when commands should really be carried out, 0 during a dry run (9C99)
  • $B5F3 - output enable flag
  • $B5F8 - address of the target's object record
  • $B5FA - address of the weapon's object record
  • $B5FC - address of the actor's object record
  • $B5FE - random number seed (9BFD)
The 28 bytes from $B5DC are backed up to $5F00 at start-up and restored when the game restarts.
