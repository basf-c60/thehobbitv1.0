C6FD: Hidden routes
Six bytes per entry, one chosen at random by 970B: the room, the address of an exit in that room's record, and the three bytes of the exit (direction, door, destination), which are blanked out at the start of the game and restored when Elrond reads the map (A6B8). Terminated by $FF. The code counts entries from $C6F7, six bytes earlier, so the first entry here is number 1.

C715 DEFB $0A,$FA,$B9,$03,$00,$0B Misty mountain: east to the narrow place
C71B DEFB $FF End marker
