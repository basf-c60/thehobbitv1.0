Actor
The character currently performing an action: Bilbo (object 0) or one of the independent characters. Held in $B5DB.
Dry run
A trial execution of a command routine to find out whether it would succeed, with no visible effects. See 9C99.
Word reference
A 12-bit offset from $6000 identifying a word in one of the dictionaries, often stored in two bytes with flag bits in the top four.
